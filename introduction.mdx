Chatwoot is an open-source customer engagement suite built as a modern alternative to tools like Intercom, Zendesk, and Salesforce Service Cloud. It brings every customer conversation — from live chat and email to WhatsApp, Facebook, Twitter, and SMS — into a single collaborative dashboard, so your support team can stop juggling tabs and start resolving issues faster.

## What You Can Do with Chatwoot

Chatwoot gives your team the tools to deliver exceptional support at scale. Here is a high-level look at what the platform covers:

<CardGroup cols={2}>
  <Card title="Multi-Channel Inboxes" icon="inbox">
    Connect website live chat, email, WhatsApp, Facebook, Instagram, Twitter, Telegram, SMS, and custom API channels — all managed from one place.
  </Card>
  <Card title="Conversations & Collaboration" icon="messages">
    Assign conversations to agents or teams, leave private notes, use @mentions, and track every interaction with a full audit trail.
  </Card>
  <Card title="Automations & Bots" icon="robot">
    Set up rule-based automations, round-robin routing, canned responses, and AI-powered chatbots to reduce repetitive work and response times.
  </Card>
  <Card title="Reports & CSAT" icon="chart-bar">
    Monitor first response time, resolution rates, agent performance, and customer satisfaction scores with built-in analytics and exportable reports.
  </Card>
</CardGroup>

## Browser & Mobile Compatibility

The Chatwoot web dashboard and live-chat widget run in all modern browsers. The table below lists the minimum supported versions.

### Web Browsers

| Browser          | Minimum Version |
| ---------------- | --------------- |
| Google Chrome    | 57              |
| Chromium         | 57              |
| Mozilla Firefox  | 52              |
| Apple Safari     | 14.1            |
| Microsoft Edge   | 16              |

### Mobile Apps

Chatwoot offers native apps for Android and iOS so your team can handle conversations on the go.

| Platform | Minimum Version |
| -------- | --------------- |
| Android  | Android 5.0     |
| iOS      | iOS 11.0        |

<Info>
  For the best experience, always use the latest stable release of your preferred browser. Older versions may lack support for some real-time features.
</Info>

## Key Capabilities at a Glance

<AccordionGroup>
  <Accordion title="Channels" icon="satellite-dish">
    Connect any combination of the following channels to your inboxes: Website Live Chat, Email, WhatsApp (Cloud API, Twilio, 360Dialog), Facebook, Instagram, Twitter, Telegram, Line, SMS (Twilio, Bandwidth), and fully custom API channels.
  </Accordion>
  <Accordion title="Team Collaboration" icon="people-group">
    Invite unlimited agents, organise them into teams (e.g. Sales, Support, Billing), assign conversations via round-robin routing, and collaborate using private notes and @mentions — without the customer ever seeing internal chatter.
  </Accordion>
  <Accordion title="Automations" icon="gears">
    Build no-code automation rules that trigger on conversation events (created, updated, resolved) to assign agents, add labels, send messages, or fire webhooks automatically.
  </Accordion>
  <Accordion title="Contacts & CRM" icon="address-book">
    Maintain a rich contact database with custom attributes, conversation history, labels, and bulk import via CSV. Contacts are automatically created when new conversations arrive.
  </Accordion>
  <Accordion title="Reports & Analytics" icon="chart-line">
    Access overview reports, agent reports, label reports, team reports, and inbox-level metrics. Export data as CSV for deeper analysis in external tools.
  </Accordion>
  <Accordion title="Integrations" icon="plug">
    Extend Chatwoot with Dialogflow, Slack, Google Translate, Dyte video calls, and any third-party service via Webhooks or the public REST API.
  </Accordion>
</AccordionGroup>
